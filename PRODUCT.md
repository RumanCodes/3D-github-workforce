# Workforce

## Register
product

An internal GitHub contribution office for 50–150 employees. Permanent team desks and product boards make recent engineering work discoverable. GitHub activity is evidence of contributions, never attendance or productivity. Shared internal repository visibility; private personal metrics retain existing permissions.

The approved direction is a daylight isometric office, restrained team colors, accessible parallel lists, keyboard controls and reduced motion. No leaderboards, chat or walkable multiplayer in v1.
